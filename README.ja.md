# 福井県観光ロケーション・トレンドレポート

福井県内のオンラインマップやWeb検索のインプレッション回数を集計し、観光ロケーションのトレンドを可視化するインタラクティブなWebアプリケーションです。

## デモ

[アプリを開く](https://code4fukui.github.io/fukui-kanko-trend-report/)

## 機能

- **地域別・全体集計**: 個別の地域やすべての福井県を集計して表示
- **時系列分析**: 日次、週次、月次のデータを分析
- **2期間比較**: 2つの異なる期間のデータを並べて比較
- **多様な指標**: 地図検索、Web検索、ルート検索、通話、ウェブサイトクリック、レビュー数、平均評点など
- **データエクスポート**: 可視化したデータをCSV形式でダウンロード

## 必要環境

特になし

## 使い方

1. エリア選択
2. 時間単位選択
3. 期間選択
4. 2期間比較（オプション）
5. データ確認
6. CSVダウンロード（オプション）

## データ・API

本アプリケーションは、[福井県観光ロケーション・トレンドデータ](https://github.com/code4fukui/fukui-kanko-trend-data)を利用しています。
